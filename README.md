# CS2 Match Predictor

Математический предиктор матчей CS2. Берёт **предстоящие матчи с HLTV** и по каждому выдаёт:

1. **Вероятность победы** каждой команды и **справедливый коэффициент** (1 / P).
2. **«Ставить от»**: минимальный коэффициент, при котором ставка выгодна с запасом 7%.
   Если у твоей БК коэффициент ниже, ставку лучше пропустить.
3. **Уровень риска**: низкий (P ≥ 70%), средний (55–70%), высокий (40–55%), очень высокий (< 40%).
4. **Карты**: вероятности точного счёта (2:0 / 2:1 / 1:2 / 0:2, для Bo5 — 3:0…0:3), тотал карт
   больше/меньше 2.5 и форы ±1.5.
5. **Стратегия** по каждому матчу:
   - **основная ставка** — победа фаворита;
   - **рискованная** — фаворит всухую;
   - **по картам** — тотал;
   - **страховка андердога** — андердог с форой +1.5.
6. **Бэктест** на прошлых матчах: как часто модель угадывает и сбываются ли её вероятности.

```
HLTV: результаты ─► история ─► Elo по картам + форма + личные встречи ─► логистическая калибровка ─► P(победы)
HLTV: расписание ──────────────────────────────────────────────────────┘        └─► модель числа карт ─► счёт, тотал, форы
```

## Установка

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env                                    # Telegram — по желанию
```

## Быстрый старт

```bash
# 1. История матчей HLTV за ~1.5 года (первый раз ~10–15 минут)
python -m cs_predictor collect --source hltv

# 2. Подбор параметров только на прошлом и честная проверка на «будущем»
python -m cs_predictor tune --until 2026-03-01
python -m cs_predictor backtest --since 2026-03-01

# 3. Прогнозы и стратегия на ближайшие 48 часов (перед этим история сама обновится)
python -m cs_predictor predict
python -m cs_predictor predict --hours 24 --top 5        # 5 подробных карточек на сутки
python -m cs_predictor predict --bo1                     # включить Bo1 (по умолчанию только Bo3/Bo5)
python -m cs_predictor predict --margin 0.10             # более осторожный запас: 10%

# 4. Раз в 30 минут обновлять прогнозы и присылать новые матчи в Telegram
python -m cs_predictor watch
```

Результаты сохраняются в `output/`:
- `strategy_*.txt` — отчёт;
- `strategy_*.csv` — все рынки по всем матчам;
- `backtest_report.md` — отчёт бэктеста.

### Пример карточки

```
━━ 1. Lynn Vision vs NEXVOID — Bo3, 29.09 16:00 МСК, ESL Challenger League Season 52 Asia-Pacific Cup 2
   История в базе: 113 / 60 матчей
   Счёт (за Lynn Vision): 2:0 47%, 2:1 27%, 1:2 14%, 0:2 12%
   Стратегия:
     • основная:             П1 Lynn Vision          74.1%  справ.  1.35  ставить от  1.44  риск низкий
     • рискованная:          Счёт 2:0 Lynn Vision    46.9%  справ.  2.13  ставить от  2.28  риск высокий
     • по картам:            Тотал карт М 2.5        59.2%  справ.  1.69  ставить от  1.81  риск средний
     • страховка андердога:  Фора NEXVOID +1.5       53.1%  справ.  1.88  ставить от  2.02  риск высокий
```

Читать так: если на П1 Lynn Vision дают 1.50, это выше 1.44, и ставка выгодна. Если дают 1.30,
то ниже справедливых 1.35, и ставку надо пропустить.

### Как считаются карты

Вероятность победы в серии пересчитывается в вероятность выиграть одну карту. Но карты внутри
матча связаны: форма дня, свои пики. Поэтому формула «карты независимы» на реальных данных
завышает долю 2:1 примерно на 6 п.п. Модель числа карт обучается на истории
(`P(3 карты) = σ(a + b·logit(2q(1−q)))`) и распределяет счёт так, чтобы он сходился с
вероятностью победы.

### Режим с линией BetBoom (необязательно, только на своём компьютере)

`python -m cs_predictor betboom` сравнивает прогнозы с живой линией BetBoom, считает EV и
выдаёт сигналы: Bo3, коэффициент 1.55–1.85, EV ≥ 7%. Из облака Claude он не работает: линия
BetBoom идёт по WebSocket. Подробности ниже.

## Линия BetBoom

Публичного API у BetBoom нет. Есть три режима (`--mode`), по умолчанию `auto` пробует их по очереди:

| Режим | Как работает | Что настроить |
|---|---|---|
| `url` | Прямой JSON-запрос к внутреннему эндпоинту сайта | `BETBOOM_JSON_URL` в `.env` |
| `playwright` | Headless Chromium открывает страницу CS2 и перехватывает все JSON-ответы | `BETBOOM_CS2_URL` в `.env` |
| `csv` | Ручной файл `data/betboom_manual.csv` | см. формат ниже |

**Как найти эндпоинт:** открой раздел CS2 на сайте BetBoom → F12 → Network → фильтр Fetch/XHR →
обнови страницу → найди запрос, в ответе которого есть названия команд и коэффициенты →
правый клик → Copy URL → вставь в `BETBOOM_JSON_URL`.

**Как устроена линия BetBoom** (проверено 29.09.2026). Сайт `betboom.ru` — только оболочка.
Спортбук подгружается виджетом с `sportbook.sporthub.bet`, а матчи и коэффициенты приходят по
WebSocket `wss://ru-ws2.sporthub.bet/api/tree_ws/v1` в бинарном формате protobuf. Обычных JSON-запросов
с линией нет. Поэтому основной режим `playwright`: виджет сам отрисовывает линию в браузере, а
скрипт читает команды и коэффициенты П1/П2 из текста страницы. Время на сайте считается московским.
Если JSON всё-таки встречается, его тоже разбирает универсальный экстрактор.

- Сервер линии отказывает браузеру с `HeadlessChrome` в User-Agent. Скрипт подставляет User-Agent обычного Chrome.
- Нужен доступ к `*.betboom.ru` и `*.sporthub.bet`. Облачный прокси Claude WebSocket не пропускает,
  поэтому режим `playwright` запускай у себя на компьютере.
- Если распознано 0 матчей или что-то не то, запусти:

```bash
python -m cs_predictor betboom-dump
```

В `data/betboom_dump/` сохранятся `page.html`, `page.txt`, `page.png` и все JSON-ответы.
Пришли `page.txt` и `page.png`, и я подгоню разбор под реальную вёрстку.

Формат ручного CSV:

```csv
start,team1,team2,odds1,odds2,best_of
2026-09-30T15:00:00Z,NAVI,G2,1.72,2.05,3
```

Если BetBoom не отдаёт формат (Bo1/Bo3), он берётся из расписания HLTV/PandaScore.
Расхождения в названиях команд («NAVI» и «Natus Vincere») решает нечёткий поиск и словарь
синонимов в `data/aliases.json`, который можно дополнять.

## Математика модели

**1. Elo по картам.** Каждая сыгранная карта обновляет рейтинги (Bo3 со счётом 2:1 даёт три
обновления). Для новых команд K-фактор повышен. После простоя больше 45 дней рейтинг частично
откатывается к среднему, потому что состав мог смениться.

**2. Маппул и вето.** У каждой команды есть поправка к рейтингу на каждой карте. Для Bo3
симулируется вето (бан-бан-пик-пик-бан-бан-десайдер): каждая сторона банит свои худшие карты
и пикает лучшие. Актуальный маппул определяется автоматически по картам, сыгранным за
последние 120 дней.

**3. От карты к серии.** Если вероятность выиграть карту равна p, то Bo3 выигрывается с
вероятностью `p²(3 − 2p)`, а при разных картах `p1·p2 + p1(1−p2)p3 + (1−p1)p2·p3`.

**4. Калибровка.** Логистическая регрессия поверх признаков: Elo-вероятность серии, форма
(результаты против ожиданий в последних 10 матчах), личные встречи за год, опыт команды,
простой. Обучается только на прошлом (walk-forward), без подглядывания в будущее.

**5. Коэффициенты.**
- Маржа: `1/k1 + 1/k2 − 1`.
- Вероятность БК без маржи считается методом power: ищется n такое, что `(1/k1)ⁿ + (1/k2)ⁿ = 1`.
- `EV = P_модели × k − 1`.
- Размер ставки: ¼ Келли, то есть `(P·k − 1)/(k − 1) × 0.25` от банка.

**6. Фильтр сигнала (режим `betboom`).** Bo3, коэффициент 1.55–1.85, EV ≥ 7%, у обеих команд не меньше 15 матчей
в истории. EV больше 30% помечается как подозрительный: такой «перевес» почти всегда означает,
что модель чего-то не знает (стендин, замена, виза). Все пороги задаются в `.env`.

## Бэктест: как читать отчёт

- **Точность**: доля угаданных победителей (50% соответствует монетке). Модель сравнивается с чистым Elo.
- **LogLoss / Brier**: качество вероятностей, чем меньше, тем лучше (монетка даёт 0.693 / 0.25).
- **Точность по уверенности**: насколько чаще модель угадывает, когда уверена на 65% и больше.
- **Калибровка**: если модель говорит «70%», должна угадывать около 70%.
- **Топ-N матчей дня**: точность N самых уверенных Bo3-прогнозов за каждый день. Это ближе всего
  к реальному сценарию использования.
- **ROI стратегии.** Исторических коэффициентов BetBoom в открытом доступе нет, поэтому скрипт
  сам копит снимки линии в `data/odds_log.csv` при каждом запуске `betboom`. Через несколько
  недель `backtest --odds-log` посчитает реальную доходность фильтра на коэффициентах BetBoom.

### Результаты на реальной истории HLTV (29.09.2026)

Данные: 16 051 матч с HLTV за 07.04.2025–29.09.2026, 1266 команд. Параметры подобраны только
на матчах до 01.03.2026 (`tune --until 2026-03-01`). Проверка шла на 7146 матчах после этой даты,
которых модель при подборе не видела: `backtest --since 2026-03-01`.

| Выборка | Матчей | Точность |
|---|---|---|
| Все матчи | 7146 | **64.6%** |
| Bo3, у обеих команд ≥15 матчей в истории | 4358 | 63.0% |
| Уверенность модели ≥ 65% | 1655 | 73.5% |
| Уверенность модели ≥ 75% | 502 | 79.7% |
| Топ-1 Bo3 дня | 213 | **76.5%** |
| Топ-3 Bo3 дня | 636 | 76.3% |

Калибровка хорошая: когда модель говорит 70–75%, она угадывает 72.3%, а при 75–80% — 77.6%.

Рынки по картам (4303 Bo3 после 01.03.2026):

| Рынок | Модель обещала | Факт |
|---|---|---|
| Счёт 2:0 фаворита (= фора −1.5) | 38.4% | 38.8% |
| Фора андердога +1.5 | 61.6% | 61.2% |
| Тотал карт Б 2.5 | 41.6% | 43.0% |
| Счёт 2:0 андердога | 19.9% | 18.2% |

Счёт и форы откалиброваны хорошо. У тотала карт сигнал слабый: доля трёхкартовых матчей почти
не зависит от разницы в силе команд и держится около 40–45%. Поэтому ставки на тотал имеют
смысл только при кэфе не ниже «ставить от».
Точность угадывания ещё не означает прибыль: у фаворитов низкие коэффициенты. Окупаемость
станет понятна после накопления `odds_log` BetBoom.

Результаты `demo` получены на синтетике: они проверяют только, что код работает.

## Честно об ограничениях

- Линия букмекера — сильный прогноз. Даже хорошие публичные модели CS угадывают около 62–67%
  матчей, и обыграть маржу на длинной дистанции сложно. Относись к сигналам как к фильтру
  кандидатов, а не как к гарантии. Прежде чем ставить деньги, проверь ROI на накопленном
  `odds_log`.
- Стендины и свежие замены автоматически не определяются. Перед ставкой проверь составы на HLTV.
- HLTV защищён Cloudflare. `curl_cffi` обычно помогает, но при частых запросах возможна блокировка.
  Не уменьшай паузы между запросами.
- Эндпоинты BetBoom могут меняться. Тогда поможет `betboom-dump`.
- Соблюдай правила сайтов и законы своей страны. Ставки связаны с риском потери денег.

## Структура

```
cs_predictor/
  __main__.py        CLI: collect / backtest / tune / predict / watch / betboom / betboom-dump / demo
  strategy.py        счёт по картам, рынки, справедливые кэфы, «ставить от», риск, карточки
  config.py          настройки и пороги (.env)
  storage.py         модель данных матча, CSV, слияние источников без дублей
  names.py           нормализация и нечёткое сопоставление названий команд
  ratings.py         Elo по картам, маппул, симуляция вето, вероятность серии
  model.py           признаки + логистическая калибровка, модель числа карт, Predictor
  odds.py            маржа, вероятности без маржи, EV, Келли
  signals.py         сведение линии BetBoom с прогнозами, фильтр, таблицы, лог коэффициентов
  backtest.py        walk-forward бэктест, метрики, симуляция ставок, подбор параметров
  notify.py          Telegram
  synthetic.py       синтетические данные для demo и тестов
  sources/hltv.py, pandascore.py, betboom.py, http.py
tests/               pytest (парсеры, математика, отсутствие заглядывания в будущее, фильтр сигналов)
```

Тесты: `python -m pytest -q`
